What this actually measures

A browser cannot send ICMP. No web API exposes raw sockets, so there is no way to run the ping command's actual protocol from a web page — and any page that claims to is timing something else and calling it ping.

What this page does instead is time a real HTTPS request to each target, with caching and credentials off and a hard abort at the timeout. That is a genuine round trip over the network you are on, and it is the right tool for "is this site slow from here". It is an upper bound on path latency, never equal to it.

  • TTFB where the server allows it. When a target sends a Timing-Allow-Origin header, the Resource Timing API hands over the phase split and the reading becomes time-to-first-byte — mostly propagation delay. Cards and rows marked total only did not get that permission, so their figure still contains server processing and transfer.
  • The first request is thrown out. It pays DNS, the TCP handshake and the TLS handshake, routinely several times the steady-state round trip. It is shown on each card, kept in the export, and excluded from every statistic.
  • An IP address is not an ICMP ping. A few do answer — 8.8.8.8, 1.1.1.1 and 9.9.9.9 serve HTTPS with certificates valid for the address, so they return a real number, but it is their web server’s round trip, not the address’s reachability. Most other addresses have no HTTPS listener or no certificate for the literal and come back unreachable, which says nothing about whether the host is up.
  • Loss is counted, not hidden. A probe that times out or never connects increments loss and breaks the chart line. A target that fails every request reads 100% loss, not an empty graph.

Baselines

A STUN binding exchange carries no TLS and no server-side work, so this is the closest a browser gets to a real network round trip. Treat it as the floor: whatever a target measures above this is protocol and application overhead, not distance.

Reading the screen

The probe path only has to reach the server. A 404 is a perfectly good round trip and is timed like any other reply, so there is no need to hunt for a file that exists — some of these targets will log 404s in devtools and the measurement is unaffected.

Each target is its own line. A red rule marks a probe that never came back; the line breaks there rather than bridging the gap. The first, cold request per host is left out.

Everything stays in this tab: targets are kept in this browser's local storage, samples exist only in memory until you export them, and no result is sent anywhere. The requests themselves obviously do reach the hosts you name.
